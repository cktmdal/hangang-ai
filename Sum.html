서포트 벡터 머신(SVM)이란 무엇일까?

최적의 경계선을 찾아 데이터를 분류하는 강력한 AI 알고리즘을 체험해보세요

📚 SVM 알고리즘이란?

SVM은 두 그룹을 가장 멀리 떨어뜨리는 경계선을 찾는 알고리즘이에요. 예를 들어, 배드민턴을 좋아하는 학생들과 댄스를 좋아하는 학생들을 나눌 때, 양쪽 그룹에서 가장 가까운 학생들(서포트 벡터)과의 거리가 최대한 멀어지는 중간선을 찾는 것과 같아요!

1️⃣ 데이터 추가

클래스 A 또는 클래스 B 버튼을 선택한 후 캔버스를 클릭하여 학습 데이터를 추가합니다.

2️⃣ 커널 선택

직선, 다항식, RBF, 시그모이드 중 하나를 선택하여 다양한 형태의 경계선을 만들 수 있습니다.

3️⃣ Cost 조정

엄격함(높은 C) vs 유연함(낮은 C)을 조절하여 경계선이 데이터를 얼마나 정확히 따라갈지 결정합니다.

4️⃣ 학습 실행

'학습 시작!' 버튼을 클릭하면 AI가 최적의 결정 경계와 서포트 벡터를 찾아냅니다.

⚙️커널 설정

💪Cost (C) 파라미터

높은 C (엄격)

오류를 거의 허용하지 않음. 데이터에 딱 맞춤 → 과적합 위험 ⚠️

낮은 C (유연)

오류를 어느정도 허용. 부드러운 경계 → 일반화 성능 ✅

🧠 커널의 종류 이해하기

직선 커널 📏

가장 단순한 형태예요. 데이터를 직선으로 나눌 수 있을 때 사용합니다. 빠르고 간단하지만, 복잡한 패턴은 분류하기 어려워요.

다항식 커널 📐

곡선으로 데이터를 나눌 수 있어요. 타원이나 포물선 같은 모양으로 경계를 만들 수 있어서 조금 더 복잡한 패턴을 분류할 수 있습니다.

RBF 커널 🎨

가장 유연한 형태예요! 점에서 가까울수록 영향이 크고, 멀수록 영향이 작아지는 원리로 아주 복잡한 패턴도 분류할 수 있어요.

시그모이드 커널 🧮

S자 곡선(sigmoid)을 사용하는 커널이에요! 신경망처럼 여러 개의 S자 함수를 조합해서 복잡하고 구불구불한 경계선을 만들 수 있습니다. 딥러닝과 연결되는 방식이라 흥미로워요!
