2-2. 지식의 표현과 추론

인공지능이 인간의 지식을 어떤 방식으로 표현하고, 규칙과 사실을 활용하여 스스로 추론하는지 배워봅시다!

오늘 우리가 할 수 있게 될 것
  • 규칙과 사실을 활용하여 지식을 컴퓨터가 처리할 수 있는 구조로 표현할 수 있어요.
  • 명제 논리와 술어 논리의 차이를 구분하고, 논리 연산자와 추론 규칙을 적용할 수 있어요.
학습 포인트: 일상언어(자연어)는 모호함이 발생하기 때문에, 컴퓨터가 처리하려면 지식을 명확하고 완전한 형태로 나타내야 합니다.

지식 표현의 주요 방식

  • 규칙 기반 전문가 시스템: 특정 분야의 전문 지식을 'If-Then(만약~라면)' 규칙 형태로 저장하여 문제 해결에 활용합니다.
  • 의미망 (Semantic Network): 개념(노드)과 간의 관계(링크)를 네트워크 그래프 구조로 시각화하여 표현합니다.
  • 프레임 (Frame): 객체의 속성 및 관련된 정보를 슬롯(Slot) 구조 형태로 묶어 상세 기술합니다.

데이터, 정보, 지식의 위계

데이터 가공되지 않은 단순한 사실이나 측정값
정보 데이터를 목적에 맞게 가공하여 의미를 부여한 값
지식 정보를 분석하고 체계화하여 문제 해결에 활용 가능한 상태
학습 포인트: '명제'란 내용이 참(True) 또는 거짓(False)임을 논리적으로 명확하게 판별할 수 있는 문장입니다.

명제 논리의 연산자와 기호

기호 읽는 방법 논리식 예시 (p: 신호등이 초록색이다 / q: 자동차가 전진한다)
~ 또는 ¬ not (부정) ¬p 신호등이 초록색이 아니다.
∧ and (논리곱) p ∧ q 신호등이 초록색이다. 그리고 자동차가 전진한다.
∨ or (논리합) p ∨ q 신호등이 초록색이다. 또는 자동차가 전진한다.
→ implies (조건) p → q 만약 신호등이 초록색이면 자동차가 전진한다.
↔ if and only if (쌍조건) p ↔ q 신호등이 초록색일 때만 자동차가 전진한다.

추론의 두 가지 방식

연역적 추론 (Deductive Reasoning)

이미 주어진 확실한 전제로부터 논리적 결론을 도출합니다. (예: 삼단논법)

귀납적 추론 (Inductive Reasoning)

개별 사례들의 관찰 결과로부터 일반적인 결론을 유도합니다.

대표적인 추론 규칙

1. 긍정 논법 (Modus Ponens)

• 규칙: p → q (합격하면 AI를 공부한다)

• 사실: p (합격했다)

• 결론: q (AI를 공부한다)

2. 삼단 논법 (Syllogism)

• 규칙 1: p → q (AI를 잘하면 코딩을 잘한다)

• 규칙 2: q → r (코딩을 잘하면 수학을 잘한다)

• 결론: p → r (AI를 잘하면 수학을 잘한다)

학습 포인트: 명제 논리는 "모든", "어떤"과 같은 한정자나 주어-술어 구조를 표현하지 못하므로 '술어 논리'를 활용합니다.

술어 논리의 주요 한정자

∀x
전칭 기호 (Universal Quantifier)

모든 x에 대하여 논리식이 성립함을 의미합니다.

∃x
존재 기호 (Existential Quantifier)

조건을 만족하는 x가 적어도 하나 이상 존재함을 의미합니다.

술어 논리 표현 예시

자연어: "모든 자율주행 자동차는 자동차이다."

술어 논리식: ∀x (SelfDrivingCar(x) → Car(x))

하이브리드형 인공지능 (Symbolic + Deep Learning)

최근 인공지능은 데이터 패턴을 학습하는 연결주의(딥러닝)와 논리적 추론을 수행하는 기호주의(지식 표현)를 결합하여 더 높은 정확도와 설명 가능성을 제공하는 하이브리드 AI 형태로 발전하고 있습니다.

실생활 활용 사례

  • 시맨틱 웹 (Semantic Web): 웹상의 자원 간 의미 관계(Ontology)를 정의하여 컴퓨터가 이해할 수 있도록 만드는 기술
  • 프로로그 (Prolog): 규칙과 사실을 기반으로 명제 논리를 추론하는 대표적인 인공지능 논리 프로그래밍 언어
