딥러닝이란?

딥러닝은 데이터 속에 숨겨진 규칙이나 패턴을 기계가 스스로 찾아내게 하는 기계학습(machine learning)의 한 갈래입니다
여러 층(layer)으로 쌓아 올린 계산 구조를 써서 학습하는 방식을 가리킵니다



생각 - "인공지능이 뇌를 그대로 흉내 낸 건가요?"
아닙니다. 인공신경망은 뇌의 신경 세포가 신호를 주고받는 모습에서 착상을 얻은 수학적 계산 구조일 뿐이고, 실제 뇌가 어떻게 작동하는지를 재현한 것이 아닙니다



1.기계학습과 딥러닝 무엇이 다른가?

딥러닝이 잘하는 것

  • 사람이 특징을 짚어 주기 어려운 사진·음성·글 같은 데이터를 다룰 수 있습니다.
  • 데이터가 충분히 많고 문제가 복잡할수록 다른 방법으로는 잡기 어려운 규칙까지 찾아냅니다.
  • 어떤 속성을 만들지 사람이 하나하나 준비하던 과정을 덜어 줍니다.

함께 따라오는 대가

  • 정할 값이 워낙 많아 데이터가 적으면 오히려 성능이 떨어집니다.
  • 수많은 계산을 반복해야 하므로 연산 성능이 좋은 장비(GPU 등)와 시간이 듭니다.
  • 왜 그런 결과가 나왔는지 사람이 따라가 설명하기 어렵습니다('블랙박스' 문제).


2. 인공신경망과 딥러닝은 무엇일까?

(1) 퍼셉트론

뉴런의 작동 방식을 모방하여 컴퓨터 프로그램으로 구현한 것으로 가중치, 편향, 활성화 함수로 구성됩니다.



🧠 생물학적 뉴런

  • 수상돌기: 다른 뉴런들로부터 신호를 받아들임
  • 시냅스: 신호의 연결 강도(중요도)를 결정함
  • 세포체: 들어온 신호들을 모아 판단함
  • 축삭돌기: 다음 뉴런으로 신호를 전달함

💻 인공 퍼셉트론

  • 입력값: 외부 데이터나 이전 층의 값을 받아들임
  • 가중치: 각 데이터의 중요도를 곱함
  • 편향: 더해진 값에 숫자 하나를 보태 판단 기준을 옮김
  • 활성화: 그 값을 보고 무엇을 내보낼지 정함
  • 출력값: 다음 퍼셉트론으로 결과를 전달함


(2) 딥러닝의 구조

  • 인공신경망: 여러 개의 퍼셉트론을 네트워크처럼 연결한 인공지능 모델로 입력층, 은닉층, 출력층으로 이루어집니다
  • 딥러닝: 여러 개의 은닉층이 있는 인공신경망입니다.
  • 활성화 함수: 선형적인 결과를 비선형적으로 바꾸는 함수로 각 상황에 따라 다양한 활성화 함수가 사용됩니다.

<모델별로 주로 사용하는 활성화 함수>

알고리즘 출력층 은닉층
예측 사용하지 않음 렐루 (ReLU)
이진 분류 시그모이드 (Sigmoid)
다중 분류 소프트맥스 (Softmax)

(3) 딥러닝의 학습

딥러닝 모델에 데이터를 넣어 출력한 결과(예측값)를 실제값과 비교하여 오차를 줄이는 방향으로 가중치와 편향을 조절하는 과정입니다

  • 순전파: 딥러닝에서 학습하기 위해 데이터를 입력하고 은닉층과 출력층을 거쳐 결과를 출력하는 과정
  • 오차 계산: 딥러닝 모델이 출력한 예측값과 실제값 사이의 차이를 계산하는 과정 (계산하는 함수는 손실함수
  • 역전파: 오차를 줄이도록 순전파의 반대 방향으로 이동하며 각 퍼셉트론의 가중치와 편향을 수정하는 과정
  • 손실함수: 오차 계산에 사용하는 함수로 목적에 따라 다양한 함수가 사용됨

<모델별로 주로 사용하는 손실함수>

모델 손실함수
예측 평균제곱오차 (MSE)
이진 분류 이진 교차 엔트로피 (BCE)
다중 분류 범주형 교차 엔트로피 (CCEE)

3. 딥러닝과 기계학습 알고리즘은 어떤 차이가 있을까?

(1) 딥러닝과 기계학습의 차이

  • 기계학습: 데이터에서 사람이 직접 특징을 추출하여 모델 학습
  • 딥러닝: 사람이 특징을 추출하지 않은 기초 데이터를 입력해도 스스로 특징을 추출하여 결과를 예측할 수 있음

(2) 딥러닝을 적용한 문제 해결 과정

  1. 문제 정의: 딥러닝 모델로 해결하기에 적절한 문제 정의
  2. 데이터 수집: 데이터 수집 및 데이터 형태와 개수 확인
  3. 데이터 전처리: 차원 변환, 데이터위 편향성을 줄이고 학습 속도를 높이기 위해 정규화, 원-핫 인코딩 실행
  4. 딥러닝 모델 구성: 입력층, 은닉층, 출력층 및 손실함수와 평가 방법 구성
    • 입력층: 입력 데이터의 특징의 개수 지정
    • 은닉층: 은닉층의 수와 각층별 퍼셉트론의 수, 활성화 함수 지정
    • 출력층: 레이블의 종류의 수대로 출력층 개수 지정 및 출력층의 활성화 함수 지정
  5. 학습: 훈련 데이터와 테스트 데이터를 입력하고 한 번에 학습할 데이터의 개수(에포크) 지정 후 학습 실행
  6. 성능 평가: 훈련 데이터와 테스트 데이터로 성능 평가

1. 이미지 데이터 처리에 뛰어난 딥러닝은 무엇이 있을까?

(1) 컴퓨터 비전의 이해

컴퓨터 비전: 이미지와 비디오와 같은 시각 데이터를 처리해 의미 있는 정보를 추출하는 인공지능 기술

주요 분야: 이미지 분류, 객체 위치 식별, 객체 탐지, 이미지 분할

(2) 합성곱 신경망(CNN)

이미지 분류에 뛰어난 성능을 보이는 딥러닝 모델로 합성곱층, 풀링층, 완전 연결층으로 구성.

  • 합성곱층: 필터(커널)라는 작은 가중치 묶음을 함께 공유하며 이미지의 특징을 추출하는 층
  • 풀링층: 합성곱층을 통과한 데이터를 여러 개의 작은 영역으로 쪼갠 후 각 영역을 대표하는 값을 출력
  • 완전 연결층: 합성곱층과 풀링층을 통해 특징이 추출된 데이터로 이미지를 분류

2. 생성형 인공지능이란 무엇일까?

  • 생성형 인공지능: 텍스트, 오디오, 이미지 등 기존 콘텐츠를 활용해 유사한 콘텐츠를 새롭게 만들어 내는 인공지능 기술
  • 생성적 적대 신경망(GAN): 대표적인 생성형 인공지능 알고리즘으로, 데이터를 생성하는 생성자와 데이터가 진짜인지 가짜인지 구분하는 감별자로 구성
    • 생성자: 새로운 콘텐츠를 생성하는 인공지능 모델
    • 감별자: 콘텐츠인지 아닌지를 감별하는 모델

3. 컴퓨터 비전 기술은 어디에 활용될까?

  • 광학 문자 인식 (OCR): 이미지 속의 글자를 추출해 텍스트 데이터로 변환하는 기술 자동차 번호판 인식 시각 보조 서비스
  • 객체 탐지: 이미지에 있는 물체의 위치를 찾고 분류하는 기술 CCTV 교통량 분석 X-ray 분석
  • 얼굴 인식: 이미지에서 얼굴 위치를 찾거나 누구의 얼굴인지 분류하는 기술 모자이크 처리 보안 시스템[cite: 72]
  • 얼굴 영상 생성: 사람의 얼굴을 수정하거나 다른 사람 또는 가상의 얼굴을 씌워 영상으로 만드는 기술 영화 촬영 디지털 복원[cite: 72]

1. 인공지능은 사람의 말소리를 어떻게 텍스트로 바꿀까?[cite: 72]

음성 인식: 사람의 말소리를 분석하여 텍스트 데이터로 바꾸는 인공지능 기술[cite: 72]

사람의 말소리를 텍스트로 바꾸는 방법[cite: 72]:

  1. 패턴 인식 (if then 방식): 이미 저장되어 있는 주파수 정보에 따라 해당 텍스트로 변환[cite: 72]
  2. 딥러닝 방식: 음성 주파수를 분석하여 음소를 추출하고 추출된 음소를 바탕으로 다양한 경우를 고려하여 확률이 높은 텍스트로 변환[cite: 72]

2. 음성 인식은 어디에 활용될까?[cite: 72]

  • 사물 인터넷이나 자연어 처리 등의 기술과 융합하여 다양한 분야에서 활용[cite: 72]
  • 기기 제어, 텍스트 기록, 외국어 교육, 자막 생성 등[cite: 72]

1. 자연어 처리란 무엇일까?[cite: 72]

자연어 처리(NLP): 인간이 사용하는 언어를 기계가 이해하고 처리할 수 있도록 하는 인공지능의 한 분야로 언어 이해와 언어 생성으로 구분[cite: 72].

구분 및 해당 분야[cite: 72]:

  • 언어 이해: 기계가 인간의 언어를 이해하도록 만드는 방법과 과정을 의미하며 문장에서 의미를 파악하는 능력이 필요 감정 분석 구문 분석 텍스트 분류 상식 추론[cite: 72]
  • 언어 생성: 기계가 인간이 이해할 수 있는 자연스러운 언어를 생성하는 방법과 과정을 의미 자동 완성 스토리 생성 캡션 생성[cite: 72]

사용자의 챗봇 활용 과정[cite: 72]:

사람의 음성 입력 ➔ 음성 인식(텍스트 문서로 전환) ➔ 언어 이해(의미와 의도 분석) ➔ 검색(필요한 정보를 인터넷에서 검색) ➔ 언어 생성(검색을 기반으로 문장 생성) ➔ 음성 합성(텍스트를 음성으로 변환하여 대답) ➔ 기계의 음성 출력[cite: 72]

2. 인공지능은 텍스트 데이터를 어떻게 인식할까?[cite: 72]

텍스트 데이터를 숫자로 변환하여 인식함. 대표적으로 원-핫 인코딩과 워드 임베딩이 있음[cite: 72].

  • 원-핫 인코딩: 단어를 나타내는 고정 길이 벡터에서 해당 단어만 1로 표현하고 나머지는 0으로 표현하는 방법[cite: 72]
  • 워드 임베딩: 학습을 통해 단어를 저차원의 실수값으로 변환하여 단어 간의 관계와 의미를 파악할 수 있도록 하는 방법[cite: 72]

3. 인공지능에서 언어 이해란 무엇일까?[cite: 72]

  • 빈도수 기반 방식: 단어나 문장이 텍스트 데이터 내에서 얼마나 자주 등장하는지를 세는 방식[cite: 72]
  • 의미론적 접근 방식: 형태소 분석, 구문 분석, 의미 분석, 개체명 분석, 담화·의도 분석 등의 과정으로 문장의 의미를 파악하는 방식[cite: 72]
    1. 형태소 분석: 문장을 형태소 단위로 분리하는 과정[cite: 72]
    2. 구문 분석: 단어들 사이의 문법적 관계를 파악하는 과정[cite: 72]
    3. 의미 분석: 문장에서 각 단어와 구문의 의미를 분석하는 과정[cite: 72]
    4. 개체명 분석: 개체명을 파악하여 단어의 의미를 이해하는 과정[cite: 72]
    5. 담화·의도 분석: 주어진 텍스트에서 전체 대화의 맥락을 고려하여 문장의 의도를 파악하는 과정[cite: 72]
  • 딥러닝을 이용한 방식[cite: 72]:
    • 텍스트 데이터는 문장에 나열된 단어의 순서에 따라 서로 다른 의미를 가지게 됨[cite: 72]
    • 순환 신경망(RNN): 이전의 정보를 기억하면서 입력되는 데이터의 순서를 기억하는 딥러닝 모델에 텍스트 데이터를 학습시키는 방식[cite: 72]
    • 순환 신경망 이후 모델의 성능이 점차 향상되어 자연어 처리 기술이 혁신적으로 발전함[cite: 72]

4. 생성형 언어 모델이란 무엇일까?[cite: 72]

  • 생성형 언어 모델(GLM): 주어진 문맥이나 입력에 대해 자연스러운 텍스트를 생성하는 인공지능 기술[cite: 72]
  • 원리: 특정 단어가 나왔을 때 다음에 자주 등장하는 단어의 패턴을 학습해 확률적으로 다음에 등장할 단어를 생성[cite: 72]

생성형 언어 모델에서 문장 생성 방법[cite: 72]:

형태소 분석
텍스트를 단어나 형태소로 나눈다.[cite: 72]
↓
임베딩
단어를 공간에 배치한다.[cite: 72]
↓
언어 모델
단어 사이의 관계와 문맥을 깊이 이해하고 문장에서 단어의 역할을 파악한다.[cite: 72]
↓
확률적 선택
다음에 나올 단어의 확률을 예측하여 새로운 문장을 생성한다.[cite: 72]
