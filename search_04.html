딥러닝이란?

딥러닝은 데이터 속에 숨겨진 규칙이나 패턴을 기계가 스스로 찾아내게 하는 기계학습(machine learning)의 한 갈래입니다
여러 층(layer)으로 쌓아 올린 계산 구조를 써서 학습하는 방식을 가리킵니다



생각 - "인공지능이 뇌를 그대로 흉내 낸 건가요?"
아닙니다. 인공신경망은 뇌의 신경 세포가 신호를 주고받는 모습에서 착상을 얻은 수학적 계산 구조일 뿐이고, 실제 뇌가 어떻게 작동하는지를 재현한 것이 아닙니다



1.기계학습과 딥러닝 무엇이 다른가?

딥러닝이 잘하는 것

  • 사람이 특징을 짚어 주기 어려운 사진·음성·글 같은 데이터를 다룰 수 있습니다.
  • 데이터가 충분히 많고 문제가 복잡할수록 다른 방법으로는 잡기 어려운 규칙까지 찾아냅니다.
  • 어떤 속성을 만들지 사람이 하나하나 준비하던 과정을 덜어 줍니다.

함께 따라오는 대가

  • 정할 값이 워낙 많아 데이터가 적으면 오히려 성능이 떨어집니다.
  • 수많은 계산을 반복해야 하므로 연산 성능이 좋은 장비(GPU 등)와 시간이 듭니다.
  • 왜 그런 결과가 나왔는지 사람이 따라가 설명하기 어렵습니다('블랙박스' 문제).


2. 인공신경망과 딥러닝은 무엇일까?

(1) 퍼셉트론

뉴런의 작동 방식을 모방하여 컴퓨터 프로그램으로 구현한 것으로 가중치, 편향, 활성화 함수로 구성됩니다.



🧠 생물학적 뉴런

  • 수상돌기: 다른 뉴런들로부터 신호를 받아들임
  • 시냅스: 신호의 연결 강도(중요도)를 결정함
  • 세포체: 들어온 신호들을 모아 판단함
  • 축삭돌기: 다음 뉴런으로 신호를 전달함

💻 인공 퍼셉트론

  • 입력값: 외부 데이터나 이전 층의 값을 받아들임
  • 가중치: 각 데이터의 중요도를 곱함
  • 편향: 더해진 값에 숫자 하나를 보태 판단 기준을 옮김
  • 활성화: 그 값을 보고 무엇을 내보낼지 정함
  • 출력값: 다음 퍼셉트론으로 결과를 전달함


(2) 딥러닝의 구조

  • 인공신경망: 여러 개의 퍼셉트론을 네트워크처럼 연결한 인공지능 모델로 입력층, 은닉층, 출력층으로 이루어집니다
  • 딥러닝: 여러 개의 은닉층이 있는 인공신경망입니다.

    층이 깊어지면 무엇이 달라질까 — 고양이 사진 알아보기

    심층 신경망은 사진을 한 번에 보고 "고양이네!"라고 아는 것이 아닙니다. 층을 지날 때마다 앞 층이 찾아 놓은 것을 재료로 삼아 조금씩 더 큰 특징을 만들어 갑니다. 아래는 그 흐름을 이해하기 쉽게 정리한 것이고, 실제로 각 층이 무엇을 찾을지는 사람이 정해 주는 것이 아니라 학습 중에 정해집니다.즉,선을 볼지 귀를 볼지까지 층이 스스로 정해 갑니다. 이것이 딥러닝의 가장 큰 특징입니다.

    1. 입력층: 사진을 이루는 수많은 픽셀(점)의 밝기 값을 그대로 받아들입니다.
    2. 은닉층 1: 이웃한 점들의 값을 비교해 선, 모서리, 색의 경계 같은 단순한 특징을 잡아냅니다.
    3. 은닉층 2: 그 선들을 조합해 눈, 코, 뾰족한 귀 같은 부분 모양을 만듭니다.
    4. 은닉층 3: 부분들이 어떤 자리에 어떻게 놓였는지를 묶어 얼굴 전체의 짜임새를 만듭니다.
    5. 출력층: 지금까지 모인 값으로 고양이일 가능성이 얼마나 되는지를 계산해 내놓습니다.
  • 활성화 함수: 선형적인 결과를 비선형적으로 바꾸는 함수로 각 상황에 따라 다양한 활성화 함수가 사용됩니다

    활성화 함수를 빼면, 층을 아무리 쌓아도 소용이 없다

    가중합과 편향은 곱하고 더하는 계산뿐입니다. 그런 층을 두 번 지나면 어떻게 될까요? 곱하고 더한 것을 다시 곱하고 더한 것이니, 정리하면 결국 또 하나의 곱하고 더하기가 됩니다. 층을 열 개, 백 개 쌓아도 마찬가지입니다. 결과는 직선 하나를 긋는 퍼셉트론 한 개와 똑같아집니다. 그러면 XOR 문제도 여전히 풀 수 없습니다.

    그래서 층과 층 사이마다 곱셈·덧셈이 아닌 다른 방식으로 값을 한 번 꺾어 주는 단계를 넣습니다. 이 단계가 활성화 함수(activation function)입니다. 활성화 함수 덕분에 층을 쌓는 일이 비로소 의미를 가집니다.

<모델별로 주로 사용하는 활성화 함수>

알고리즘 출력층 은닉층
예측 사용하지 않음 렐루 (ReLU)
이진 분류 시그모이드 (Sigmoid)
다중 분류 소프트맥스 (Softmax)


계단 함수

기준을 넘으면 1, 아니면 0. 단호하지만 얼마나 넘었는지는 알려 주지 않습니다.

"ON / OFF 똑딱이 스위치"
개념: 기준선(0)을 넘으면 무조건 1(합격/전원 ON), 못 넘으면 무조건 0(불합격/전원 OFF)을 내보냅니다.
예) (시험 합격 여부): 60점 이상이면 합격(1), 59점 이하는 불합격(0)입니다. 59점이나 0점이나 똑같이 "불합격"이고, 60점이나 100점이나 똑같이 "합격"입니다. 중간 단계가 전혀 없이 결과가 극단적으로 꺾입니다.
단점: 중간이 없기 때문에 "얼마나 잘했는지" 세밀한 차이를 표현할 수 없습니다.

시그모이드 함수

0과 1 사이를 부드럽게 오갑니다. 얼마나 그럴듯한지를 함께 담아 넘길 수 있습니다.

"부드러운 조명 조절기(디머)"
개념: S자 모양의 부드러운 곡선으로, 입력값이 아무리 크거나 작아도 결과를 0과 1 사이의 연속적인 값(확률)으로 바꿔줍니다.
예) (비 올 확률):: "오늘 비가 올까?"라는 질문에 단칼에 "응/아니"라고 하지 않고, "비 올 확률 85%"처럼 확률 형태로 대답해 줍니다. 점수가 약간 바뀌면 출력값도 부드럽게 조금씩 바뀝니다.
단점: 값이 너무 커지거나 작아지면 변화 폭이 아주 미미해져서, 인공지능이 깊어질수록 학습이 잘 안 되는 문제(경사 손실 문제)가 생깁니다.

ReLU(렐루) 함수

음수는 0으로 잘라 내고, 양수는 있는 그대로 넘깁니다. 0에서 한 번 꺾인다는 점이 핵심입니다.

"음수는 차단하고, 양수는 들어오는 대로!"
개념: 음수($x < 0$)가 들어오면 무조건 0으로 차단하고, 양수($x \ge 0$)가 들어오면 들어온 값 그대로 통과시킵니다.
예) (카페 최소 주문 금액): 손해가 나는 행동(음수)은 아예 끊어버려 0으로 만듭니다. 이익이 나는 행동(양수)은 성과를 낸 만큼 그대로 인정해 줍니다. (예: 10 만큼 잘하면 10, 100 만큼 잘하면 100을 출력)
단점: 계산이 훨씬 단순하고 빠르며, 시그모이드처럼 깊은 신경망에서 학습이 멈추는 현상이 없어 현재 딥러닝에서 가장 많이 쓰이는 스위치입니다.


(3) 딥러닝의 학습

딥러닝 모델에 데이터를 넣어 출력한 결과(예측값)를 실제값과 비교하여 오차를 줄이는 방향으로 가중치와 편향을 조절하는 과정입니다

  • 순전파: 딥러닝에서 학습하기 위해 데이터를 입력하고 은닉층과 출력층을 거쳐 결과를 출력하는 과정
  • 오차 계산: 딥러닝 모델이 출력한 예측값과 실제값 사이의 차이를 계산하는 과정 (계산하는 함수는 손실함수
  • 역전파: 오차를 줄이도록 순전파의 반대 방향으로 이동하며 각 퍼셉트론의 가중치와 편향을 수정하는 과정
  • 손실함수: 오차 계산에 사용하는 함수로 목적에 따라 다양한 함수가 사용됨

순전파(forward propagation)

데이터를 입력층에 넣으면 값이 층을 차례로 지나 출력층까지 앞으로 흘러갑니다. 각 층에서 가중치를 곱하고 편향을 더하고 활성화 함수를 지나는, 지금까지 배운 그 계산입니다. 끝에서 예측이 나오고, 정답과 비교해 손실을 측정합니다.

역전파(backpropagation)

이번에는 출력층에서 입력층 쪽으로 거슬러 가며, "이 오차에 너는 얼마나 책임이 있는가"를 가중치마다 몫으로 나누어 매깁니다. 그 몫이 큰 가중치는 많이, 작은 가중치는 조금 고칩니다. 얼마나 고칠지는 경사하강법이 정합니다.

<모델별로 주로 사용하는 손실함수>

모델 손실함수
예측 평균제곱오차 (MSE)
이진 분류 이진 교차 엔트로피 (BCE)
다중 분류 범주형 교차 엔트로피 (CCEE)

3. 딥러닝과 기계학습 알고리즘은 어떤 차이가 있을까?

(1) 딥러닝과 기계학습의 차이

  • 기계학습: 데이터에서 사람이 직접 특징을 추출하여 모델 학습
  • 딥러닝: 사람이 특징을 추출하지 않은 기초 데이터를 입력해도 스스로 특징을 추출하여 결과를 예측할 수 있음

(2) 딥러닝을 적용한 문제 해결 과정

  1. 문제 정의: 딥러닝 모델로 해결하기에 적절한 문제 정의
  2. 데이터 수집: 데이터 수집 및 데이터 형태와 개수 확인
  3. 데이터 전처리: 차원 변환, 데이터위 편향성을 줄이고 학습 속도를 높이기 위해 정규화, 원-핫 인코딩 실행
  4. 딥러닝 모델 구성: 입력층, 은닉층, 출력층 및 손실함수와 평가 방법 구성
    • 입력층: 입력 데이터의 특징의 개수 지정
    • 은닉층: 은닉층의 수와 각층별 퍼셉트론의 수, 활성화 함수 지정
    • 출력층: 레이블의 종류의 수대로 출력층 개수 지정 및 출력층의 활성화 함수 지정
  5. 학습: 훈련 데이터와 테스트 데이터를 입력하고 한 번에 학습할 데이터의 개수(에포크) 지정 후 학습 실행
  6. 성능 평가: 훈련 데이터와 테스트 데이터로 성능 평가

딥러닝은 어디에 쓰이고 있을까?

사람이 특징을 짚어 주기 어려운 자리마다 딥러닝이 들어간다

아래 분야에는 공통점이 하나 있습니다. 모두 사진, 소리, 글, 영상처럼 표로 정리하기 어려운 데이터를 다룬다는 점입니다. "무엇을 봐야 하는지"를 사람이 말로 적어 주기 어려운 자리에서 딥러닝이 힘을 냅니다.

분야 무엇을 학습하나 특히 조심할 점
자율주행 카메라와 센서로 들어온 장면에서 차선, 신호등, 사람, 다른 차를 가려낸다 학습 때 본 적 없는 상황(폭설, 공사 구간)에서 판단이 흔들릴 수 있다
의료 영상 판독 엑스선·CT 영상에서 병으로 의심되는 부분의 모양과 밝기 패턴을 찾는다 최종 판단은 사람이 한다. 왜 그렇게 봤는지 설명하기 어렵다는 점이 특히 문제가 된다
음성 인식·번역 소리의 파형과 글의 앞뒤 순서를 함께 학습해 말을 글로, 글을 다른 언어로 옮긴다 사투리나 배경 소음처럼 학습 데이터에 적게 들어 있던 경우에 성능이 떨어진다
게임·전략 판단 바둑판이나 게임 화면의 상태를 보고 다음 수의 값어치를 매긴다 규칙이 분명한 판 위에서 강하다. 규칙이 흐릿한 현실 문제에 그대로 옮기기는 어렵다
창작 도구 수많은 그림·음악·글에서 형태와 결을 학습해 새로운 것을 만들어 낸다 학습에 쓴 원작자의 권리, 만들어진 결과물의 책임을 누가 지는가 하는 문제가 따른다

1. 이미지 데이터 처리에 뛰어난 딥러닝은 무엇이 있을까?

(1) 컴퓨터 비전의 이해

컴퓨터 비전: 이미지와 비디오와 같은 시각 데이터를 처리해 의미 있는 정보를 추출하는 인공지능 기술

주요 분야: 이미지 분류, 객체 위치 식별, 객체 탐지, 이미지 분할


전통적인 컴퓨터 비전

사람이 직접 이미지 데이터의 특징(모서리, 색상 등)을 추출하는 규칙을 정하고, 그 규칙으로 모델을 학습시키는 방식입니다.

딥러닝 기반 컴퓨터 비전 (CNN)

인공신경망이 수많은 데이터를 반복 학습하며 무엇을 볼지까지 스스로 정합니다. 비슷한 장면이 붙은 사진을 충분히 많이 학습하면, 물체 하나하나뿐 아니라 여러 물체가 함께 놓인 상황에도 이름표를 붙일 수 있습니다. 다만 이것도 학습해 본 장면에 한해서이고, 처음 보는 상황에서는 엉뚱한 이름표를 달기도 합니다.



(2) 합성곱 신경망(CNN)

이미지 분류에 뛰어난 성능을 보이는 딥러닝 모델로 합성곱층, 풀링층, 완전 연결층으로 구성.

  • 합성곱층: 필터(커널)라는 작은 가중치 묶음을 함께 공유하며 이미지의 특징을 추출하는 층
  • 풀링층: 합성곱층을 통과한 데이터를 여러 개의 작은 영역으로 쪼갠 후 각 영역을 대표하는 값을 출력
  • 완전 연결층: 합성곱층과 풀링층을 통해 특징이 추출된 데이터로 이미지를 분류


합성곱과 풀링 — 특징을 뽑는 두 가지 손질

숫자표에서 어떻게 ‘모서리’나 ‘무늬’를 찾아낼까?

합성곱 신경망이 이미지를 다루는 방식

왜 앞서 배운 구조를 그대로 쓰지 않을까?

지난 시간의 신경망은 앞 층의 모든 값을 다음 층의 모든 뉴런에 이어 붙이는 구조였습니다. 이 구조에 사진을 넣으려면 숫자표를 한 줄로 쭉 늘어놓아야 하는데, 그러면 두 가지 문제가 생깁니다.

① 이웃이라는 정보가 사라진다

모서리나 무늬는 바로 옆 칸과 비교해야 보입니다. 한 줄로 늘어놓는 순간 어느 칸이 어느 칸의 위·아래였는지가 없어집니다.

② 정할 값이 너무 많아진다

가로세로 200칸짜리 컬러 사진 한 장이면 숫자가 12만 개입니다. 이것을 전부 이어 붙이면 학습으로 정해야 할 가중치가 감당할 수 없이 불어납니다.

그래서 합성곱 신경망은 사진을 한 줄로 펴지 않고 격자 모양 그대로 두고, 작은 창을 옮겨 가며 이웃한 칸끼리만 계산합니다. 그 계산이 합성곱입니다.

합성곱(convolution) — 작은 창을 옮겨 가며 훑는다

커널(kernel)은 숫자 몇 개가 적힌 작은 숫자판입니다. 이 커널을 사진의 왼쪽 위 구석에 겹쳐 놓고, 겹친 칸끼리 곱해서 모두 더합니다. 그 결과 숫자 하나가 나옵니다. 그다음 커널을 한 칸 오른쪽으로 옮겨 같은 계산을 하고, 오른쪽 끝에 닿으면 한 줄 내려와 다시 왼쪽부터 훑습니다. 이렇게 모은 숫자들을 다시 격자로 늘어놓은 것을 특징 지도(feature map)라고 합니다.

그림을 읽는 법

입력에서 가운데 세로줄만 값이 큽니다(어두운 칸). 커널은 가운데 열에 1, 양옆에 −1이 적혀 있어 ‘가운데만 밝고 양옆은 어두운 자리’를 만나면 큰 값을 내놓습니다. 그래서 특징 지도에서도 가운데 열만 27로 크게 나왔습니다. 즉 이 커널은 세로줄이 있는 자리를 찾아내는 창 노릇을 한 것입니다.

커널의 숫자를 다르게 두면 가로줄이나 비스듬한 줄을 찾는 창이 됩니다. 중요한 것은 — 이 숫자들을 사람이 정해 주는 것이 아니라, 학습하면서 정해진다는 점입니다. 커널의 숫자가 바로 지난 시간에 배운 가중치이고, 사진을 많이 볼수록 이 숫자가 고쳐집니다.

풀링(pooling) — 크게 줄여 요약한다

합성곱을 한 번 거쳐도 특징 지도의 숫자는 여전히 많습니다. 풀링은 특징 지도를 작은 구역으로 나눈 뒤 구역마다 대표값 하나만 남기는 손질입니다. 가장 흔한 방식은 가장 큰 값만 남기는 것입니다.

얻는 것 ① 계산이 가벼워진다

다음 층으로 넘길 숫자가 크게 줄어드니, 층을 더 쌓아도 계산을 감당할 수 있습니다.

얻는 것 ② 위치가 조금 어긋나도 버틴다

구역 안에서 가장 큰 값만 남기므로, 찾던 무늬가 한두 칸 옮겨 가도 같은 대표값이 나옵니다. 사진마다 물체가 정확히 같은 자리에 있을 수는 없으니 꼭 필요한 성질입니다.

치르는 대가도 있습니다

줄이는 만큼 버려지는 정보가 생깁니다. 구역 안에서 최댓값을 뺀 나머지는 사라지므로, 정확한 위치나 미세한 경계가 중요한 문제(예: 앞에서 본 세분화)에서는 풀링을 적게 쓰거나 다른 방법을 씁니다. 풀링을 많이 넣을수록 좋아지는 것이 아닙니다.

이 둘을 번갈아 쌓으면

합성곱 신경망은 합성곱 → 풀링을 여러 번 반복한 뒤, 마지막에 지난 시간에 배운 값을 이어 붙이는 층을 붙여 이름표를 고릅니다. 앞쪽 층은 짧은 선이나 색의 경계처럼 단순한 무늬에 반응하고, 뒤쪽 층으로 갈수록 그 무늬들이 모인 더 큰 모양에 반응하게 됩니다.

한 가지 조심할 것

“앞쪽 층은 선, 뒤쪽 층은 얼굴”처럼 사람이 층마다 역할을 정해 준 것이 아닙니다. 각 층의 커널 숫자는 학습으로 정해지고, 그 결과 그런 경향이 나타나는 것입니다. 또 층을 무작정 늘린다고 좋아지지도 않습니다 — 정할 값이 늘어 더 많은 데이터와 시간이 필요하고, 앞 시간에 본 과적합에 빠지기도 쉽습니다.

2. 음성 인식은 어디에 활용될까?

  • 기기 제어, 텍스트 기록, 외국어 교육, 자막 생성 등

1. 자연어 처리란 무엇일까?

자연어 처리(NLP): 인간이 사용하는 언어를 기계가 이해하고 처리할 수 있도록 하는 인공지능의 한 분야로 언어 이해와 언어 생성으로 구분.

구분 및 해당 분야:

  • 언어 이해: 기계가 인간의 언어를 이해하도록 만드는 방법과 과정을 의미하며 문장에서 의미를 파악하는 능력이 필요 감정 분석 구문 분석 텍스트 분류 상식 추론
  • 언어 생성: 기계가 인간이 이해할 수 있는 자연스러운 언어를 생성하는 방법과 과정을 의미 자동 완성 스토리 생성 캡션 생성

사용자의 챗봇 활용 과정:

사람의 음성 입력 ➔ 음성 인식(텍스트 문서로 전환) ➔ 언어 이해(의미와 의도 분석) ➔ 검색(필요한 정보를 인터넷에서 검색) ➔ 언어 생성(검색을 기반으로 문장 생성) ➔ 음성 합성(텍스트를 음성으로 변환하여 대답) ➔ 기계의 음성 출력

2. 인공지능은 텍스트 데이터를 어떻게 인식할까?

텍스트 데이터를 숫자로 변환하여 인식함. 대표적으로 원-핫 인코딩과 워드 임베딩이 있음.

  • 원-핫 인코딩: 단어를 나타내는 고정 길이 벡터에서 해당 단어만 1로 표현하고 나머지는 0으로 표현하는 방법
  • 워드 임베딩: 학습을 통해 단어를 저차원의 실수값으로 변환하여 단어 간의 관계와 의미를 파악할 수 있도록 하는 방법

3. 인공지능에서 언어 이해란 무엇일까?

  • 빈도수 기반 방식: 단어나 문장이 텍스트 데이터 내에서 얼마나 자주 등장하는지를 세는 방식
  • 의미론적 접근 방식: 형태소 분석, 구문 분석, 의미 분석, 개체명 분석, 담화·의도 분석 등의 과정으로 문장의 의미를 파악하는 방식
    1. 형태소 분석: 문장을 형태소 단위로 분리하는 과정
    2. 구문 분석: 단어들 사이의 문법적 관계를 파악하는 과정
    3. 의미 분석: 문장에서 각 단어와 구문의 의미를 분석하는 과정
    4. 개체명 분석: 개체명을 파악하여 단어의 의미를 이해하는 과정
    5. 담화·의도 분석: 주어진 텍스트에서 전체 대화의 맥락을 고려하여 문장의 의도를 파악하는 과정
  • 딥러닝을 이용한 방식:
    • 텍스트 데이터는 문장에 나열된 단어의 순서에 따라 서로 다른 의미를 가지게 됨
    • 순환 신경망(RNN): 이전의 정보를 기억하면서 입력되는 데이터의 순서를 기억하는 딥러닝 모델에 텍스트 데이터를 학습시키는 방식
    • 순환 신경망 이후 모델의 성능이 점차 향상되어 자연어 처리 기술이 혁신적으로 발전함

4. 생성형 언어 모델이란 무엇일까?

  • 생성형 언어 모델(GLM): 주어진 문맥이나 입력에 대해 자연스러운 텍스트를 생성하는 인공지능 기술
  • 원리: 특정 단어가 나왔을 때 다음에 자주 등장하는 단어의 패턴을 학습해 확률적으로 다음에 등장할 단어를 생성
