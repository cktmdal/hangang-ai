학습 모델의 성능을 평가하고 개선하기

테스트 데이터를 사용하여 분류 모델의 성능을 평가하고, 적절한 평가 지표(정확도, 정밀도, 재현율, F1-점수)를 통해 모델을 다각도로 분석할 수 있습니다.

1. 혼동행렬(Confusion Matrix)의 이해

실제 값과 모델의 예측 값에 따라 결과를 4가지 영역으로 구분합니다.

구분 예측값
참 (Positive) 거짓 (Negative)
실제값 참 (Positive) TP (True Positive)
참으로 예측, 실제 참		 FN (False Negative)
거짓으로 예측, 실제 참
거짓 (Negative) FP (False Positive)
참으로 예측, 실제 거짓		 TN (True Negative)
거짓으로 예측, 실제 거짓

2. 성능 평가 지표 계산 공식

정확도 (Accuracy) = (TP + TN) / (TP + TN + FP + FN)

정밀도 (Precision) = TP / (TP + FP)

재현율 (Recall) = TP / (TP + FN)

F1-점수 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
TIP: 질병 진단 모델에서는 실제 병이 있는 환자를 병이 없다고 잘못 예측하는 위험을 줄이기 위해 재현율(Recall)이 중요하며, 스팸 메일 분류 모델에서는 일반 메일을 스팸으로 오분류하는 문제를 방지하기 위해 정밀도(Precision)가 중요한 지표가 됩니다.

총 100명의 환자 데이터를 바탕으로 예측한 아래 결과를 보고 문제에 답해보세요.
* 소수점 둘째 자리까지 입력하세요. (예: 0.85)
예측 (Predicted)
암 (Positive) 정상 (Negative)
실제
(Actual)		 암 (Positive) 40 (TP) 10 (FN)
정상 (Negative) 5 (FP) 45 (TN)
1. 정확도 (Accuracy)
계산식: (TP + TN) / (TP + TN + FP + FN)
2. 정밀도 (Precision)
계산식: TP / (TP + FP)
3. 재현율 (Recall)
계산식: TP / (TP + FN)
4. F1-Score
계산식: 2 * (Precision * Recall) / (Precision + Recall)

스팸X 30 (FP) 60 (TN)
