1.분류 모델 진단 평가 실습

조건: T =크리스마스 선물 받음, F = 크리스마스 선물 못받음

분류 모델을 활영하여 내가 크리스마스 선물을 받을수 있는지 예측한다.

아래의 실제값과 모델 예측 결과 데이터를 바탕으로 혼동 행렬을 완성하고, 평가 지표를 계산하여 입력하세요.

실제 TFTTFTFTFTTF
모델예측 TTTFTTFTFFTF

혼동 행렬 (Confusion Matrix) 완성

예측값: T 예측값: F
실제값: T 참으로 예측, 실제참 거짓으로 예측, 실제참
실제값: F 참으로 예측, 실제거짓 거짓으로 예측, 실제거짓

성능 평가 지표 계산 공식

정확도 (Accuracy) = (TP + TN) / (TP + TN + FP + FN)

정밀도 (Precision) = TP / (TP + FP)

재현율 (Recall) = TP / (TP + FN)

F1-점수 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)



성능 평가 지표 입력
