📚 k-Means 클러스터링이란?

k-Means는 "비슷한 친구끼리 모으기" 알고리즘이에요. 마치 체육시간에 비슷한 실력의 학생들끼리 모둠 선을 만드는 것처럼, 데이터들을 k개의 그룹으로 자동으로 나눠줍니다! 스무고개 게임처럼 질문하는 게 아니라, 거리를 재서 가장 가까운 그룹으로 배정해요.

1️⃣ 데이터 추가

캔버스를 클릭하여 데이터를 추가하거나 초기 데이터를 사용합니다.

2️⃣ 클러스터 설정

몇 개의 그룹으로 나눌지 클러스터 개수를 설정합니다.

3️⃣ 학습 실행

'자동 실행' 또는 '한 스텝'으로 클러스터링 과정을 관찰합니다.

4️⃣ 결과 확인

데이터가 어떻게 그룹으로 나뉘는지 확인해봅니다.

⚙️클러스터 설정

*몇 개의 그룹으로 나눌까요?

*데이터 크기를 비슷하게 맞춰요

*더 좋은 결과를 위해 멀리 떨어진 점들을 선택해요

*최대 몇 번까지 시도할까요?

*더 좋은 결과를 위해 여러 번 시도
