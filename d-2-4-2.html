인공지능의 텍스트 데이터 인식 방식

기계가 글자를 이해할 수 있도록 숫자로 변환하는 대표적인 두 가지 방법

핵심 원리

텍스트 데이터 ➔ 숫자로 변환하여 인식

🏷️ 원-핫 인코딩 (One-Hot Encoding)

단어를 나타내는 고정 길이 벡터에서 해당 단어만 1로 표현하고 나머지는 0으로 표현하는 방법

예시: [사과, 바나나, 포도] 벡터 표현
사과
1
0
0
바나나
0
1
0
포도
0
0
1
특징: 직관적이지만 단어 종류가 늘어날수록 빈 공간(0)이 과도하게 커지는 단점이 있습니다.

📍 워드 임베딩 (Word Embedding)

학습을 통해 단어를 저차원의 실수값으로 변환하여 단어 간의 관계와 의미를 파악할 수 있도록 하는 방법

예시: 의미 공간(좌표)상의 단어 배치
사과 [0.2, 0.8]
바나나 [0.4, 0.7]
자동차 [0.9, 0.2]
특징: 의미가 비슷한 단어(예: 사과와 바나나)끼리 가까운 공간에 위치하여 단어 간의 관계와 의미를 학습합니다.
