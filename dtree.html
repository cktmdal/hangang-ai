질문을 통해 데이터를 분류하는 직관적인 AI 알고리즘을 체험해보세요

📚 의사결정 트리란?

의사결정 트리는 "예/아니오" 질문을 반복하여 데이터를 분류하는 알고리즘이에요. 마치 스무고개 게임처럼, "X값이 300보다 작나요?", "Y값이 200보다 크나요?" 같은 질문으로데이터를 단계적으로 나누어 최종 답을 찾아요!

1️⃣ 데이터 추가

클래스 A, B, 또는 C를 선택한 후 캔버스를 클릭하여 학습 데이터를 추가합니다.

2️⃣ 파라미터 조정

트리의 깊이, 노드 크기 등을 조절하여 트리가 얼마나 복잡해질지 결정합니다.

3️⃣ 학습 실행

'학습 시작!' 버튼을 클릭하면 AI가 최적의 질문들을 찾아 트리를 만듭니다.

4️⃣ 결과 확인

만들어진 트리 구조와 결정 경계선을 확인하고 이해해봅니다.

⚙️트리 파라미터

*마지막 노드에 필요한 최소 데이터 수

*더 이상 나누지 않을 최소 크기

*트리가 얼마나 깊어질 수 있는지

*한 클래스가 이 비율 이상이면 분할 중지

🧠 파라미터가 트리에 미치는 영향

🔢 리프 노드 최소 개수

마지막 노드(리프)에 있어야 하는 최소 데이터 개수예요. 값이 크면 트리가 단순해지고, 값이 작으면 세밀한 분류가 가능해요.

🔍 최소 분할 크기

이 크기보다 작은 그룹은 더 이상 나누지 않아요. 값이 크면 일찍 멈춰서 단순한 트리가 되고, 값이 작으면 더 많이 나눠요.

📊 최대 깊이

트리가 얼마나 깊어질 수 있는지 제한해요. 깊이가 작으면 단순한 트리, 깊이가 크면 복잡하고 세밀한 트리가 만들어져요.

🎯 다수 기준(%)

한 클래스가 이 비율 이상이면 더 이상 나누지 않아요. 90%면 조금만 섞여도 계속 나누고, 50%면 반반만 되어도 멈춰요.

🎓 의사결정 트리의 장단점

✅ 장점

  • • 이해하기 쉽고 해석이 직관적이에요
  • • 시각화가 가능해서 설명하기 좋아요
  • • 숫자 데이터와 범주형 데이터 모두 사용 가능해요
  • • 데이터 전처리가 거의 필요 없어요
  • • 3개 이상의 클래스도 분류할 수 있어요

⚠️ 단점

  • • 과적합되기 쉬워요 (훈련 데이터에만 잘 맞음)
  • • 데이터가 조금만 바뀌어도 트리가 크게 달라져요
  • • 복잡한 관계는 표현하기 어려워요
  • • 대각선 경계선은 만들기 어려워요
